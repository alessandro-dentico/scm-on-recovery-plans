# Replication package

**Fiscal Discipline, Uneven Regional Consequences: Evidence from the Italian National Health Service**<br>
Alessandro Dentico and Cinzia Di Novi<br>
HEDG Working Papers 26/19, University of York<br>
Working paper: https://www.york.ac.uk/media/economics/documents/hedg/workingpapers/2026/2619.pdf<br>
IDEAS/RePEc: https://ideas.repec.org/p/yor/hectdg/26-19.html

## Software requirements

Stata 17 or later. Two user-written packages, installed automatically by `master.do`:

```
ssc install synth
ssc install synth_runner
```

## How to run

1. Clone or download this repository.
2. Open `master.do` and set the `drive` global to the repository's root folder path.
3. Run `master.do` from start to finish. It calls every other `.do` file, in order, and reproduces every table and figure in the paper.

## Folder structure

```
Do/       every .do file called by master.do
Data/
  Raw HFA/       raw data, as downloaded (see "Data source" below)
  Reshaped HFA/  intermediate per-variable files, generated by data_preparation.do
  Panel/         final analysis panel (panel_HFA.dta), generated by data_preparation.do
Output/   every figure and table produced by the pipeline; already
          populated with the paper's own figures and tables, so they
          can be inspected without running the code
Log/      one text log per .do file
```

`Data/Reshaped HFA/`, `Data/Panel/`, and `Log/` are empty until `master.do` is run, each with a `.gitkeep` placeholder so the folder exists before the first run. `Output/` is already populated with the paper's figures and tables; running `master.do` regenerates and overwrites them.

## Data source

All three variables come from ISTAT's *Health for All* (HFA) database, the Italian National Institute of Statistics' repository of regional health indicators:
https://www.istat.it/sistema-informativo-6/health-for-all-italia/

The HFA data-extraction application is Windows-only. Each indicator was queried for all 20 Italian regions and the full available year range, exported as a `.txt` table, then saved as a semicolon-delimited, UTF-8 `.csv` file. The three files in `Data/Raw HFA/` are named after their 4-digit ISTAT indicator code:

| File        | Indicator                                   |
|-------------|----------------------------------------------|
| `9110.csv`  | SSN personnel rate, per 1,000 inhabitants     |
| `7343.csv`  | Patient out-migration rate, %                 |
| `0180.csv`  | Total fertility rate (placebo outcome)        |

The data is public and freely downloadable from the link above; no access restrictions apply.
